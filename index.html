Objetos principales de JavaScript

1. Objeto History

El objeto History permite navegar por el historial del navegador, pero no deja ver las páginas visitadas.

Propiedad

  • length: cantidad de páginas visitadas.

Métodos

Método Descripción
back() Regresa a la página anterior.
forward() Va a la siguiente página.
go() Se mueve a otra página del historial.

Ejemplo

<script>
function atras(){
    window.history.back();
}
</script>

<button onclick="atras()">Atrás</button>

2. Objeto Document

El objeto Document representa toda la página web y permite acceder a sus elementos.

Propiedades

  • document.body
  • document.title
  • document.images

Métodos

  • getElementById()
  • getElementsByTagName()
  • getElementsByName()

Modificar contenido

  • innerHTML
  • setAttribute()
  • style

Ejemplo

<button onclick="cambiar()">Cambiar</button>

<p id="texto"></p>

<script>
function cambiar(){
    document.getElementById("texto").innerHTML="Hola Mundo";
}
</script>

3. Objeto Form

El objeto Form sirve para trabajar con formularios y obtener datos del usuario.

  • text
  • textarea
  • radio
  • checkbox
  • select
